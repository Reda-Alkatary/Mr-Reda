موقع الأستاذ رضا القطاري
========================

طريقة التشغيل:
1) فك الضغط عن الملف.
2) افتح index.html مباشرة في المتصفح.

الملفات:
- index.html : الصفحة الرئيسية
- styles.css : التصميم والحركات
- script.js  : المواعيد والفلاتر والتفاعل
- assets      : صور المدرس

لتغيير الاسم أو رقم الهاتف:
- ابحث داخل index.html و script.js عن الاسم أو الرقم واستبدله.

ملاحظة:
الموقع يعمل محلياً، ويحتاج الإنترنت فقط لتحميل خط Google عند أول تشغيل.
